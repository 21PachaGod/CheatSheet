ML: Clustering e Segmentacao de Clientes

Enquadramento Teorico

O Descritivo Tecnico exige explicitamente a elaboracao de operacoes de ML com "Clusters (single link, complete link, kmeans, etc)". Esta secao cobre os tres metodos.
  • Clustering Hierarquico Aglomerado: Constroi uma hierarquia de baixo para cima, onde cada observacao comeca no seu proprio cluster e os pares mais proximos sao progressivamente fundidos.
  • Single Linkage (Ligacao Simples): Distancia entre clusters = distancia minima entre quaisquer pontos. Tende a formar cadeias longas (chaining effect).
  • Complete Linkage (Ligacao Completa): Distancia entre clusters = par de pontos mais afastado. Produz clusters mais compactos e esfericos.
  • K-Means: Algoritmo de particao que divide o espaco em K grupos minimizando a distancia euclidiana quadratica ao centroide.
  • Silhouette Score: Avalia a qualidade do agrupamento (-1 a +1). Valores proximos de +1 indicam clusters bem definidos.
  • StandardScaler: Normaliza dados para media 0 e variancia 1 (evita que variaveis com maior magnitude dominem o calculo das distancias).

1. K-Means - Segmentacao de Clientes (Dados Frutose)

Cenario de prova: O departamento de marketing pretende agrupar clientes com base no valor total gasto e na quantidade total de fruta comprada (Kg) para campanhas direcionadas. 
import pandas as pd
from sklearn.cluster import KMeans
import matplotlib.pyplot as plt

# 1. Ingestao dos dados
df_sales = pd.read_csv('data/FactSales.csv', sep=';', decimal=',')
df_customers = pd.read_csv('data/DimCostumer.csv')
df_products = pd.read_csv('data/DimProduct.csv', sep=';', decimal=',')

# 2. Merge das tabelas
df_merged = df_sales.merge(df_customers, on='CustomerKey', how='left')
df_merged = df_merged.merge(df_products, on='ProductKey', how='left')

# 3. Criar feature e agregar por cliente
df_merged['TotalGasto'] = df_merged['QuantityKg'] * df_merged['UnitPrice']
customer_behavior = df_merged.groupby('CustomerKey').agg({
    'TotalGasto': 'sum',
    'QuantityKg': 'sum'
}).reset_index()

# 4. Selecionar variaveis de interesse
X = customer_behavior[['TotalGasto', 'QuantityKg']]

# 5. Aplicar K-Means com 3 clusters
kmeans = KMeans(n_clusters=3, random_state=42, n_init='auto')
customer_behavior['Cluster'] = kmeans.fit_predict(X)

# 6. Visualizacao
plt.scatter(customer_behavior['TotalGasto'], customer_behavior['QuantityKg'],
            c=customer_behavior['Cluster'], cmap='viridis')
plt.xlabel('Total Gasto (EUR)')
plt.ylabel('Quantidade Comprada (Kg)')
plt.title('Segmentacao de Clientes - K-Means (k=3)')
plt.colorbar(label='Cluster')
plt.show()

2. Clustering Hierarquico (Single e Complete Linkage)

Exemplo com dados sinteticos de clientes retalhistas: Volume_Kg (quantidade agregada) e Valor_Gasto (faturacao total). Os dados foram criados em tres patamares: clientes de pequeno porte, grossistas e intermedios. 
import numpy as np
import matplotlib.pyplot as plt
from scipy.cluster.hierarchy import linkage, dendrogram
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score

# 1. Dados de teste: [Volume_Kg, Valor_Gasto]
compras_clientes = np.array([
    [5.0, 25.0],    # Perfil Pequeno Retalho
    [6.2, 28.0],
    [4.8, 22.5],
    [50.0, 200.0],  # Perfil Grossista
    [55.5, 220.0],
    [48.0, 190.0],
    [15.0, 120.0],  # Perfil Margem Elevada
    [18.0, 130.0],
    [14.5, 115.0],
])

# 2. Normalizacao (requisito previo para distancias euclidianas)
escalador = StandardScaler()
dados_padronizados = escalador.fit_transform(compras_clientes)

# 3. Clustering Hierarquico
matriz_single = linkage(dados_padronizados, method="single")    # Ligacao Simples
matriz_complete = linkage(dados_padronizados, method="complete") # Ligacao Completa

# 4. Dendrogramas
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 4))
dendrogram(matriz_single, ax=ax1)
ax1.set_title("Dendrograma - Single Linkage")
ax1.set_xlabel("Indice do Ponto")
ax1.set_ylabel("Distancia Euclidiana")

dendrogram(matriz_complete, ax=ax2)
ax2.set_title("Dendrograma - Complete Linkage")
ax2.set_xlabel("Indice do Ponto")
ax2.set_ylabel("Distancia Euclidiana")
plt.tight_layout()
plt.show()

# 5. K-Means + Silhouette Score para validacao
modelo_kmeans = KMeans(n_clusters=3, random_state=42, n_init="auto")
rotulos = modelo_kmeans.fit_predict(dados_padronizados)
silhueta = silhouette_score(dados_padronizados, rotulos)

print("--- Resultados K-Means ---")
print(f"Rotulos: {rotulos}")
print(f"Silhouette Score: {silhueta:.4f}")
print("Centroides (espaco padronizado):")
print(modelo_kmeans.cluster_centers_.round(3))

3. Metodo do Cotovelo (Elbow Method)

Para determinar o numero ideal de clusters, testar varios valores de K e observar onde a inercia (soma das distancias quadraticas ao centroide) deixa de diminuir significativamente. 
inercias = []
K_range = range(2, 8)

for k in K_range:
    km = KMeans(n_clusters=k, random_state=42, n_init='auto')
    km.fit(dados_padronizados)
    inercias.append(km.inertia_)

plt.plot(K_range, inercias, 'bo-')
plt.xlabel('Numero de Clusters (K)')
plt.ylabel('Inercia')
plt.title('Metodo do Cotovelo')
plt.show()
