ML: Q-Learning (Aprendizagem por Reforco)

Enquadramento Teorico

O Q-Learning e um algoritmo de Aprendizagem por Reforco (Reinforcement Learning), livre de modelo (model-free) e fora da politica (off-policy). O agente aprende uma politica otima interagindo com o ambiente.
  • Matriz Q - Q(s, a): Tabela que guarda o valor de utilidade esperado ao tomar a acao a no estado s.
  • Equacao de Bellman:
Q(s,a) ← Q(s,a) + α [ R + γ max Q(s',a') - Q(s,a) ]
  • α (Learning Rate): Velocidade com que nova informacao sobrepoee a antiga (0 < α ≤ 1).
  • γ (Discount Factor): Peso das recompensas futuras vs. imediatas (0 ≤ γ < 1).
  • ε (Epsilon-Greedy): Equilibrio entre exploracao (acoes aleatorias) e aproveitamento (melhor acao conhecida).

Definicao do Ambiente de Teste

Cenario logistico linear simplificado com 5 estados (0 a 4):
  • Estado 0: Ponto de partida do operador de armazem.
  • Estado 4: Zona de expedicao (objetivo final, recompensa = +100).
  • Estados 1, 2 e 3: Postos intermedios de controlo (penalizacao = -1).
  • Acoes: 0 = Esquerda, 1 = Direita.

Codigo Completo com Solucao Comentada

import numpy as np

# 1. Parametros do Ambiente
NUM_ESTADOS = 5       # Estados de 0 a 4
NUM_ACOES = 2         # 0: Esquerda, 1: Direita
ESTADO_OBJETIVO = 4   # Estado final com recompensa maxima

# 2. Hiperparametros do Q-Learning
alpha = 0.1           # Taxa de aprendizagem
gamma = 0.9           # Fator de desconto
epsilon = 0.2         # Probabilidade de exploracao
num_episodios = 600   # Numero total de episodios de treino

# Inicializacao da Tabela Q com zeros (5 estados x 2 acoes)
q_table = np.zeros((NUM_ESTADOS, NUM_ACOES))

print("--- Tabela Q Inicial ---")
print(q_table)

# 3. Ciclo Principal de Treino
for episodio in range(num_episodios):
    estado_atual = 0  # Comecar sempre no estado 0

    while estado_atual != ESTADO_OBJETIVO:
        # Politica Epsilon-Greedy
        if np.random.uniform(0, 1) < epsilon:
            acao = np.random.choice([0, 1])         # Exploracao
        else:
            acao = np.argmax(q_table[estado_atual, :])  # Aproveitamento

        # Transicao de estado
        if acao == 1:
            proximo_estado = min(estado_atual + 1, NUM_ESTADOS - 1)
        else:
            proximo_estado = max(estado_atual - 1, 0)

        # Recompensa
        if proximo_estado == ESTADO_OBJETIVO:
            recompensa = 100.0
        else:
            recompensa = -1.0

        # Atualizacao da Tabela Q (Equacao de Bellman)
        max_q_futuro = np.max(q_table[proximo_estado, :])
        diferenca_temporal = (
            recompensa + (gamma * max_q_futuro) - q_table[estado_atual, acao]
        )
        q_table[estado_atual, acao] += alpha * diferenca_temporal

        estado_atual = proximo_estado

# 4. Resultados
print("\n--- Tabela Q Final (Convergida) ---")
print("Estado | Esquerda (0) | Direita (1)")
for estado in range(NUM_ESTADOS):
    print(f"  {estado}    |    {q_table[estado, 0]:6.2f}    |   {q_table[estado, 1]:6.2f}")

# 5. Politica Otima Aprendida
print("\n--- Politica Otima por Estado ---")
nomes_acoes = {0: "Mover para a Esquerda", 1: "Mover para a Direita"}
for s in range(NUM_ESTADOS - 1):
    melhor_acao = np.argmax(q_table[s, :])
    print(f"No Estado {s}, a decisao otima e: {nomes_acoes[melhor_acao]}")
