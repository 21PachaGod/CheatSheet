1. Elementos Visuais em Script Python no Power BI

Exigência Explícita do Descritivo Técnico: "Poderá ainda ser requerido do candidato demonstrar a capacidade de criar um elemento visual em script R ou Py dentro do PBI".
Como funciona no Power BI:
  1. No Power BI Desktop, clica no ícone Elemento visual do Python (Py) no painel de visualizações.
  2. Arrasta as colunas necessárias para o campo Valores.
  3. O Power BI cria automaticamente o DataFrame com o nome dataset, eliminando linhas duplicadas.
  4. Colas o código de visualização no editor de script e clicas no botão Executar (Play).

Visualizar dispersão de vendas (Quantidade vs TotalGasto) com centróides:

# Código colado no visual Python do Power BI
# O Power BI já cria automaticamente: dataset = pandas.DataFrame(...)
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans

# 1. Obter dados do Power BI
df = dataset.dropna()

# 2. Executar K-Means se as colunas forem TotalGasto e QuantityKg
if 'TotalGasto' in df.columns and 'QuantityKg' in df.columns:
    X = df[['TotalGasto', 'QuantityKg']]
    kmeans = KMeans(n_clusters=3, random_state=42, n_init='auto')
    df['Cluster'] = kmeans.fit_predict(X)

    # 3. Desenhar gráfico
    plt.figure(figsize=(7, 4.5))
    scatter = plt.scatter(df['TotalGasto'], df['QuantityKg'], c=df['Cluster'], cmap='viridis', alpha=0.7, edgecolors='k')
    plt.scatter(kmeans.cluster_centers_[:, 0], kmeans.cluster_centers_[:, 1], s=200, c='red', marker='X', label='Centróides')
    plt.xlabel('Total Gasto (€)', fontsize=10)
    plt.ylabel('Quantidade (Kg)', fontsize=10)
    plt.title('Segmentação de Clientes (K-Means)', fontsize=12, fontweight='bold')
    plt.grid(True, linestyle='--', alpha=0.5)
    plt.legend()
    plt.tight_layout()
    plt.show()

4. SQL Server / SQLEXPRESS — Queries Essenciais

A lista de infraestruturas inclui SQLEXPRESS e SQL Server Management Studio (SSMS). As consultas seguintes cobrem a ingestão, agregação e criação de vistas para o Power BI. 
-- 1. Ingestão agregada para alimentar o Power BI ou Python
SELECT 
    f.CustomerKey,
    c.CustomerName,
    COUNT(f.SalesKey) AS TotalTransacoes,
    SUM(f.QuantityKg) AS TotalKg,
    SUM(f.QuantityKg * f.UnitPrice) AS TotalFaturado,
    SUM(f.ProfitAmount) AS LucroTotal,
    ROUND(SUM(f.ProfitAmount) / NULLIF(SUM(f.QuantityKg * f.UnitPrice), 0) * 100, 2) AS MargemPct
FROM FactSales f
LEFT JOIN DimCostumer c ON f.CustomerKey = c.CustomerKey
GROUP BY f.CustomerKey, c.CustomerName
HAVING SUM(f.QuantityKg * f.UnitPrice) > 100
ORDER BY TotalFaturado DESC;

-- 2. Identificação de Produtos com Rutura de Stock
SELECT 
    p.ProductKey,
    p.ProductName,
    s.StockActual,
    s.PontoReposicao,
    CASE 
        WHEN s.StockActual = 0 THEN 'Rutura Crítica'
        WHEN s.StockActual < s.PontoReposicao THEN 'Abaixo do Ponto de Reposição'
        ELSE 'Stock Normal'
    END AS EstadoStock
FROM DimProduct p
INNER JOIN StockPolo s ON p.ProductKey = s.ProductKey
WHERE s.StockActual < s.PontoReposicao;

-- 3. Criar Vista para o Power BI (Boa prática de arquitetura)
CREATE VIEW vw_ResumoVendasMensais AS
SELECT 
    d.CalendarYear,
    d.MonthNumberOfYear,
    p.CategoryName,
    SUM(f.QuantityKg * f.UnitPrice) AS ReceitaTotal,
    SUM(f.ProfitAmount) AS LucroTotal
FROM FactSales f
JOIN DimDate d ON f.DateKey = d.DateKey
JOIN DimProduct p ON f.ProductKey = p.ProductKey
GROUP BY d.CalendarYear, d.MonthNumberOfYear, p.CategoryName;

5. Equivalentes em Linguagem R (Alternativa da Prova)

O descritivo permite usar Python ou R. Caso prefiras ou a prova peça scripts em R: 
# 1. Leitura e Preparação
df_sales <- read.csv("data/FactSales.csv", sep=";", dec=",")
df_products <- read.csv("data/DimProduct.csv", sep=";", dec=",")
df_merged <- merge(df_sales, df_products, by="ProductKey", all.x=TRUE)

# 2. Clustering K-Means em R
dados_cluster <- aggregate(cbind(TotalGasto = QuantityKg * UnitPrice, QuantityKg) ~ CustomerKey, data=df_merged, sum)
X <- scale(dados_cluster[, c("TotalGasto", "QuantityKg")])
km <- kmeans(X, centers=3, nstart=25)
dados_cluster$Cluster <- km$cluster

# 3. Clustering Hierárquico (Single e Complete Linkage) em R
d <- dist(X, method="euclidean")
hc_single <- hclust(d, method="single")
hc_complete <- hclust(d, method="complete")
par(mfrow=c(1, 2))
plot(hc_single, main="Single Linkage", xlab="", sub="")
plot(hc_complete, main="Complete Linkage", xlab="", sub="")

# 4. Regressão Linear em R
modelo_reg <- lm(ProfitAmount ~ QuantityKg + UnitPrice + DiscountPct, data=df_merged)
summary(modelo_reg)

# 5. Árvore de Decisão em R (rpart)
library(rpart)
library(rpart.plot)
df_merged$AltoLucro <- as.factor(ifelse(df_merged$ProfitAmount > 10, 1, 0))
arvore_r <- rpart(AltoLucro ~ QuantityKg + UnitPrice + StandardCost, data=df_merged, method="class")
rpart.plot(arvore_r)
