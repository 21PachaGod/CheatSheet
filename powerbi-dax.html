2. Medidas DAX Essenciais

Vendas, Lucro e Margens

// Total de Vendas (Receita Bruta)
Total Vendas = SUMX(FactSales, FactSales[QuantityKg] * FactSales[UnitPrice])

// Lucro Total
Lucro Total = SUM(FactSales[ProfitAmount])

// Quantidade Total (Kg)
Total Kg = SUM(FactSales[QuantityKg])

// Margem de Lucro (%)
Margem Lucro % = DIVIDE([Lucro Total], [Total Vendas], 0) * 100

// Ticket Medio por Transacao
Ticket Medio = DIVIDE([Total Vendas], COUNTROWS(FactSales), 0)

// Desconto Total
Total Desconto = SUM(FactSales[DiscountAmount])

// Numero de Transacoes
Nr Transacoes = COUNTROWS(FactSales)

// Numero de Clientes Distintos
Nr Clientes = DISTINCTCOUNT(FactSales[CustomerKey])

Inteligencia Temporal (Time Intelligence)

// Vendas do Ano Anterior (YoY)
Vendas Ano Anterior = CALCULATE([Total Vendas], SAMEPERIODLASTYEAR(DimDate[Date]))

// Variacao Anual (%)
Variacao YoY % = DIVIDE(
    [Total Vendas] - [Vendas Ano Anterior],
    [Vendas Ano Anterior],
    0
) * 100

// Vendas Acumuladas no Ano (YTD)
Vendas YTD = TOTALYTD([Total Vendas], DimDate[Date])

// Vendas do Mes Anterior
Vendas Mes Anterior = CALCULATE([Total Vendas], PREVIOUSMONTH(DimDate[Date]))

// Media Movel de 3 Meses
Media Movel 3M = AVERAGEX(
    DATESINPERIOD(DimDate[Date], MAX(DimDate[Date]), -3, MONTH),
    [Total Vendas]
)

Rankings e Top N

// Ranking de Produtos por Vendas
Rank Produto = RANKX(
    ALL(DimProduct[ProductName]),
    [Total Vendas], , DESC, DENSE
)

// Ranking de Lojas por Lucro
Rank Loja = RANKX(
    ALL(DimStore[StoreName]),
    [Lucro Total], , DESC, DENSE
)

// Top 5 Clientes (para usar em filtros visuais)
Top 5 Clientes = IF(
    RANKX(ALL(DimCostumer[CustomerName]), [Total Vendas], , DESC) <= 5,
    [Total Vendas],
    BLANK()
)

Medidas Avancadas e Condicionais

// Classificacao de Vendas (Semaforo)
Classificacao Venda =
SWITCH(
    TRUE(),
    [Margem Lucro %] >= 30, "Alta",
    [Margem Lucro %] >= 15, "Media",
    "Baixa"
)

// Percentagem do Total Geral
% do Total = DIVIDE(
    [Total Vendas],
    CALCULATE([Total Vendas], ALL(FactSales)),
    0
)

// Vendas com Filtro de Contexto Removido
Vendas Sem Filtro Produto = CALCULATE(
    [Total Vendas],
    REMOVEFILTERS(DimProduct)
)

3. Power Query (ETL) - Passos Comuns

O Power Query e usado para a ingestao e transformacao de dados antes de chegarem ao modelo. Passos tipicos na prova:
  1. Get Data > Text/CSV: Importar os 5 ficheiros CSV.
  2. Delimiter: Selecionar ; (ponto e virgula) para ficheiros europeus.
  3. Decimal Separator: Alterar para , (virgula) nas colunas numericas.
  4. Detect Data Type: Validar que colunas numericas nao ficaram como texto.
  5. Remove Duplicates: Aplicar nas tabelas dimensionais pelas chaves primarias.
  6. Replace Values: Substituir nulos em DiscountAmount por 0.
  7. Add Column > Custom Column: Criar TotalGasto = [QuantityKg] * [UnitPrice].
  8. Close & Apply: Carregar todas as tabelas para o modelo.

4. Boas Praticas para Dashboards

  • KPIs no topo: Cards com Total Vendas, Lucro, Nr Transacoes e Margem %.
  • Grafico de barras: Top 10 produtos por vendas ou lucro.
  • Grafico de linhas: Evolucao temporal de vendas (mensal/trimestral).
  • Mapa: Vendas por localizacao de loja (se DimStore tiver coordenadas).
  • Tabela/Matriz: Detalhe de vendas por produto e loja com drill-down.
  • Slicers: Filtros por ano, trimestre, produto e loja.
  • Formatacao condicional: Cores de semaforo na margem de lucro.
  • Tooltips personalizados: Detalhes extras ao passar o rato sobre barras/pontos.
